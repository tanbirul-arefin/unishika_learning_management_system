Python - Functions

☆ Share Edit ⋮
Oct 25, 2026 10:30 AM ◆ Python for Beginners ＋ Add Tag

1. What is a Function?

  • A function is a block of code that performs a specific task.
  • It helps us to reuse code and make the program organized.
  • We can define a function using the def keyword.
Python▢⛶
1  def greet():
2      print("Hello, UniShikha!")
3
4  greet()  # function call

2. Function with Parameters

  • We can pass values to a function using parameters.
Python▢⛶
1  def add(a, b):
2      return a + b
3
4  result = add(5, 3)
5  print(result)  # Output: 8

3. Return Value

  • A function can return a value using the return statement.
  • If we don’t use return, the function returns None by default.

4. Types of Functions

  • Built-in, user-defined, anonymous (lambda), and recursive functions.

5. Example Programs

Create a function, pass arguments, and use its return value wherever you need it.
